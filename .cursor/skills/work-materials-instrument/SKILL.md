# 工作材料规程（Instrument）

## 必读

执行任务前阅读 [instruments/work-materials-instrument.md](../../../instruments/work-materials-instrument.md)。

## 执行要点

1. 将 `materials/`（及任务指定的其他仓库内路径）视为**唯一**事实与原始数据来源。
2. 输出中关键数据必须带**路径 + 定位**；无定位则不得断言。
3. 计算前确认存在**共识文件**（`materials/consensus.md`、`materials/consensus/`、`docs/consensus.md` 或用户指定）；公式与变量含义**只引用该文件**，不自行发明口径。
4. 未获用户当次明确授权时，**不进行网络检索**以补数据。
5. 信息不足时列出缺口，**不编造**。
6. 分析类产出默认写入 **`results/`**，并标注 `materials/` 溯源。

## 交付前

对照规程第七节自检清单逐项确认。
