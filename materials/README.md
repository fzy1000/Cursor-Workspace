# 工作材料目录

将完成工作所依赖的**原始材料**放在本目录（或子目录）中。Agent 与规程要求：

- **分析、引用、计算输入**应优先且默认仅使用本目录及任务中明确包含的其他**仓库内路径**下的文件。
- 建议在文件名或子文件夹名中体现日期、版本或业务主题，便于在引用条目中写清来源。
- **共识与口径**（公式、定义、分类标准）见仓库根目录 `docs/consensus.md`，亦可使用 `materials/consensus.md` 或 `materials/consensus/`（以任务约定为准）。
- 基于本目录材料生成的**报告、图表、导出表**等产出物，默认放在 **`results/`**，不在此目录覆盖原件。

不要将密钥、令牌、个人隐私原件以未脱敏形式提交到公开仓库。
