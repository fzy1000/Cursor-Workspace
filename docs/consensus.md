# 计算与口径共识

## 1. 术语与定义

- **周收益率**：相邻两个净值报告日 \(t-1,t\) 之间，\(r_t = \mathrm{NAV}_t/\mathrm{NAV}_{t-1}-1\)。适用于材料中为**周度净值**且行间为时间顺序相邻周的情形。  
- **重叠样本**：同一行上，所研究的多只产品净值字段**均非空**的观测。  
- **Pearson 线性相关系数**：对配对样本 \((x_i,y_i)\) 按本文 §2.2 公式计算，记为 \(r_{xy}\)。

## 2. 公式与算法

### 2.1 周收益率

\[
r_t = \frac{\mathrm{NAV}_t}{\mathrm{NAV}_{t-1}} - 1
\]

### 2.2 Pearson 相关系数

\[
r_{xy} = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}
{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2}\sqrt{\sum_{i=1}^{n}(y_i - \bar{y})^2}}
\]

### 2.3 弱线性相关（本项目表述）

当 \(|r_{xy}| < 0.30\) 时，在报告与图表中可表述为**弱线性相关**（经验阈值，非假设检验结论）。

## 3. 与材料字段的对应关系

| 材料 | 字段 | 变量含义 |
|------|------|----------|
| `materials/CTA&混合中性_周度净值序列.xlsx`，`Sheet` | `净值日期` | 报告期末日 |
| 同上 | `对冲9号累计净值` | 产品 B 的累计净值 \(\mathrm{NAV}^B\) |
| 同上 | `CTA实盘净值` | 产品 C 的累计净值 \(\mathrm{NAV}^C\) |

周收益：\(x_i\) 为 B 的周收益，\(y_i\) 为 C 的周收益，在重叠样本上按时间顺序配对。
