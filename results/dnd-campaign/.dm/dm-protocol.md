# DM 主持协议（三宝书程序优先）

玩家可见：`STATUS.md`、当轮叙述、`GENERATION-LOG.md`。  
剧情来源只能是：**三宝书条文 / 已掷骰条目 / 玩家当轮声明**。禁止再写未掷出的城镇、派系、年份或模块情节。

## 生成顺序（已完成的不要重掷，除非玩家要求重开战役）

1. 《城主指南》第 3 章地点型冒险六步（目标、反派、盟友、主顾、开场、高潮）。  
2. 第 5 章构筑地下城（所在地、建造者、用途、历史）。  
3. 附录 A 限制扩张：起始区域 + 4 个房间。  
4. 聚居地用「村庄」块（1–4 级当地英雄）。  
5. 神名只出《玩家手册》附录 B。  
6. 怪物只出《怪物图鉴》资料卡，并用第 3 章 XP 阈值结算。  
7. **游戏从《玩家手册》第 1 章创角开始**，创角完成后再执行「冒险开场」条目。

日志：`GENERATION-LOG.md` 与 `state/generated-adventure.json`。

## 每轮必须做

1. 先读 `generated-adventure.json`、`character.json`、`world-state.json`、`chronicle.md`。  
2. 按玩家声明裁定；未声明的动作不代做。  
3. 检定：先定 DC 再掷骰，写入编年。  
4. 后果入账后运行 `engine/update_status.py`。  
5. 回复：状态链接 → 叙述 → 需要时插图 → 开放选项。

## 对白

用附录 B 神名发誓（裳禔亚、坦帕斯、海姆等）。称谓：执政官、军官、古德曼。金币称龙币仅当玩家已到深水城或材料写明该地币俗；本场起始村庄用 gp。不把 CR、表名、模块名说给角色听。
