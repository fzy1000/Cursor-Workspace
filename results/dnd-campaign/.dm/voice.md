# 对白与叙述语体

玩家可见的场面必须像费伦商路上的中译奇幻，不像当代闲聊。

`style/` 目录目前只有幻灯片样本，**没有**奇幻书面规范。本场对白以本文件为准。

## 要像什么

三宝书中译的口气：能说出口，略沉、略旧，不是辞赋，也不是市井快餐店点单。

- 称呼：客官、阁下、这位先生；雇工直呼其名。听不准受国姓时不要硬改成西方名，称「先生」即可。
- 路上的词：商路、西行、市集、挽马、货箱、守夜、干粮、城门。金币仍称 gp。
- 深水城是远方的大名，口吻里要有距离，不当成隔壁一站。
- 神名只出附录 B，且只在这人会呼的时候呼。行路商人可把泰摩拉挂在嘴边。

## 不要像什么

禁止现代口语与职场腔，包括但不限于：聊天、搞定、没问题、OK、行吧、谁都听过、都往那边凑、你是读书人、比划一下、出门前摸一下不丢人（可改成更贴神坛的说法）。

禁止把对白写成电报：一句一个短谓语往外蹦。  
禁止武侠江湖切口硬套（掌门、赏银、走一遭）。  
禁止用调查口吻审人。商路行人识得施法者的行头：法术书、奥术法器、长棍，以及当面施法。看见了就当看见了，不许装傻问「带着这些做什么」「是不是读书人」。分不清法师、术士、邪术师时，只称「法师」或「会法术的」。商人的反应是忌惮与算计，不是好奇盘问：布匹怕火、夜里要不要这人出手、别惊了马。不跪称大人。

## 各人气味

| 人 | 气味 |
|----|------|
| 戈尔斯塔格 | 冷、实在、先货后路。已认出冯是会法术的。话少，不装傻。称阁下，比待脚夫多一分距离，仍不献殷勤。对雇工像赶牲口一样吩咐。 |
| 达文、安德 | 粗、短。骂马、骂石头。不抢货主的话。 |
| 珊德瑞 | 利落，像管店的。不热心介绍身世。 |
| 兰德尔 | 司事口吻，文一点，仍是小镇庙里的人，不是大城学士。 |
| 路伊蒽 | 热心碎嘴，乡下旅店。可呼泰摩拉，不说模块词。 |
| 格里姆（未揭穿） | 平、慢、像抄书的。不抢话。 |

写 NPC 反应前先看角色着装。冯此刻外露：普通衣服、法术书、水晶法器、长棍；出镇时当面施过法。商路上的人认得出这是会法术的，不许再写成「看不懂行囊」。

## 叙述

一句一件事。景物用路上能摸到的东西：辙沟、挽具、篷布、尘土。不要写旁白解说设定。
