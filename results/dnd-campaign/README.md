# D&D 5e 文字跑团（三宝书程序）

DM 按仓库内三宝书**生成并主持**，不另写一套自拟长篇剧情。

## 玩家怎么玩

1. 打开 [角色状态 STATUS.md](STATUS.md)  
2. 先完成《玩家手册》第 1 章创角（当前在第 1 步：选种族）  
3. 创角结束后，开场使用已掷出的「尸体与地图」条目  
4. 完整掷骰记录：[GENERATION-LOG.md](GENERATION-LOG.md)

## 材料出处

| 用途 | 路径 |
|------|------|
| 创角六步、标准数组、种族/职业/背景/装备/战斗/法术 | `materials/dnd-5e-三宝书/DND_5E_玩家手册CN.pdf` |
| 核心假想、村庄、地点型冒险表、地下城表、附录A、XP阈值 | `materials/dnd-5e-三宝书/DND_5E_城主指南CN.pdf` |
| 资料卡 | `materials/dnd-5e-三宝书/DND_5E_怪物图鉴CN.pdf` |
| 神名 | 玩家手册附录 B |

公式只采用手册已写明的算法（属性调整值、1 级生命值、熟练+2、遭遇倍数等）。
