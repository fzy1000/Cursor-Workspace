# 《长路暮铃》—— D&D 5e 文字跑团

DM 主持的**单人战役**。规则与世界观依据仓库内三宝书；开场地点与时代取自被遗忘国度公开地理。玩家的每一次选择都会写入记忆系统，并改写后续 NPC 态度、派系声望与世界时钟。

## 如何进行（玩家）

1. 打开并随时回看：[角色状态 STATUS.md](STATUS.md)
2. 用自然语言描述角色要做什么（可附带「我想用说服检定」「我拔剑」等）。也可第一人称对白，或第三人称描述（手册第 8 章两种扮演）。
3. DM 按《玩家手册》的三步循环裁定：描述环境 → 你声明行动 → 叙述结果（需要时掷 d20）。
4. 不要元游戏翻看 `.dm/`（内含剧透）。

本场钩子是典型的剑湾冒险：酒馆、告示、废塔、怪物与更深处的东西。

## 记忆系统

| 文件 | 作用 |
|------|------|
| `state/world-state.json` | 日期、地点、旗帜、NPC 态度、派系声望、世界时钟、未选角色去向 |
| `state/character.json` | 当前 PC 完整数据源 |
| `state/chronicle.md` | 按回合记录选择与后果（可审计） |
| `engine/update_status.py` | 由 JSON 重写 `STATUS.md`，避免状态文档与记忆脱节 |
