# D&D 5e 文字跑团（三宝书）

DM 按仓库内三宝书主持。本场人物已定：**冯**（受国人人类法师，混乱善良）。

## 玩家怎么玩

1. 打开 [角色状态 STATUS.md](STATUS.md)  
2. 信仰与专长对照：[options-faith-feats.md](options-faith-feats.md)（本轮仍可改默认）  
3. 本场只有一条线：同事的信 → 林边书阁的末页 → 另一个也要那一页的人  
4. 选用记录（不是全表连掷）：[GENERATION-LOG.md](GENERATION-LOG.md)

上一版「山隘口迷宫」全表稿与更早的安费尔自拟开场均已作废。
