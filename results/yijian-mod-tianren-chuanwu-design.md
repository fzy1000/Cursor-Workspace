## 2. 心法：风云太极经

**定位**：被动心法（占被动槽）。动画与 UI **沿用云相太极**；机制 = 云相框架 + 流云生存/叠劲 + 自创 10 级武当增伤。

**与原版关系**

| 原版 | 并入方式 |
|------|----------|
| 云相太极 | 太极层数、反制、刀/拳剑联动框架、10 级受击反击 |
| 流云太极 | 命中叠「云劲」、按最大气血百分比护盾 |
| 自创 | 10 级：每层太极 +15% **武当派招式**伤害 |

**建议不再强制绑定**「仅太极神功/四象无极功」——本 MOD 为天人自创，可改为：**装备任意武当派标记招式时生效**（实现：Buff 条件 Tag = `Wudang` / 门派字段，照抄游戏内「武当拳掌+10%」类判定）。

### 2.1 等级效果（设计稿）

| 等级 | 名称 | 效果 |
|------|------|------|
| 1 | 风云初汇 | 战斗开始获得 **1 层【太极】**（持续至战斗结束，可叠层，上限 **5 层**） |
| 2 | — | 【太极】反制伤害 **+50%**（云相 4 级为 ×2，此处可设为 +50% 增量或沿用 ×2） |
| 3 | — | 使用 **武当派**招式命中时，**30%** 几率再获得 1 层【太极】 |
| 4 | 云相归一 | 同云相 4 级：开战 1 层太极；太极状态下 **反制伤害 ×200%**；**武当刀法、玄虚刀法**伤害提升（保留原云相刀加成数值） |
| 5 | — | 命中敌人时获得 **【云劲】** 1 层（2 回合）：下一段攻击伤害 **+15%**（流云机制） |
| 6 | — | 获得【云劲】时，生成 **太极云盾**：吸收相当于 **最大气血 8%** 的伤害，持续 **2 回合** |
| 7 | 无极同调 | 同云相 7 级：暴击附加减防；进入无极后施招 **高概率保留太极层数**；无极范围扩大（数值照抄云相 7 级） |
| 8 | — | 【云劲】上限 **3 层**，每层额外 **+5%** 拳掌/剑招伤害（流云加强） |
| 9 | — | 受击时 **消耗 1 层【太极】** 发动 **太极拳/太极剑法** 反击（云相 10 级机制，动画沿用云相） |
| 10 | **天人武当** | **新增**：每层【太极】使 **武当派招式伤害 +15%**（5 层满 = **+75%**，仅对 Tag 为武当的外功/绝式生效，不含江湖武学） |

### 2.2 MOD 实现要点

```
克隆源：Skills 表 → 云相太极 行
修改：
  - InternalName / DisplayName → 风云太极经
  - Description → 天人遗武叙事文案
  - LevelEffects[1..10] → 上表（L4/L7/L9 可先原样复制云相再改 L10）
  - BuffReferences → 新建 Buff「太极」「云劲」「太极云盾」或复用流云/云相已有 Buff ID 改系数
  - Animation / Icon → 保持云相太极引用
L10 新增 Buff（示例逻辑）：
  - 触发：被动常驻
  - 公式：WudangSkillDamageMul = 1 + 0.15 * TaijiStack
  - 条件：Skill.School == Wudang（字段名以解包为准）
```

## 3. 轻功：纵云梯

**定位**：主动轻功。**动画克隆 `云涛晓雾凌波舞`**；机制为「凌波舞武当化」——保留再动/闪避/集气核心，视觉与描述改为梯云纵一脉。

### 3.1 等级效果

| 等级 | 效果 |
|------|------|
| 基础 | **2 回合 CD**。使用后获得 **【纵云】**（原凌波改名的同一 Buff 框架）：集气 **+50%**，闪避 **+25%**，移动 **无视阻挡**；每回合消耗 **15%** 真气，真气 **&lt;20%** 时移除 |
| 4 | 【纵云】下每次移动叠加 **1 层灵动**；**50%** 几率获得 **1～2 层聚气** |
| 7 | 【纵云】下侧击/背击免伤 **+15%**；每移动 1 格，集气 **+5%**（单场最高 **+50%**） |
| 10 | 身法 **+35**；使用轻功后 **可再次行动**；闪避成功时对攻击者施加 **刺目**（同云涛晓雾 10 级） |

### 3.2 武当差异化（相对云涛晓雾）

| 项目 | 云涛晓雾凌波舞 | 纵云梯（建议） |
|------|----------------|----------------|
| 主题 | 司马铃/上官虹水系凌波 | 武当梯云、纵云而上 |
| 可选加强 | — | 首次进入【纵云】时，**+1 层【太极】**（与风云太极经联动，需在 Buff 里写 CrossRef） |
| 真气消耗 | 15%/回合 | 可维持 15%，或降为 **12%** 作为「加强版」微调 |

**克隆源**：`云涛晓雾凌波舞` → 改 Buff 名 `凌波`→`纵云`，描述与 Icon 换武当系。

## 4. 拳掌三式：太极绵掌（暂定名）

**定位**：武当 **2 式拳掌**（三格：一式 / 二式 / 三式），底稿 **绵掌** 的【绵掌】Debuff 机制，整组为 **一套 3 招式 MOD**（非化功绵掌那种单绝式）。

**核心特效（全三式共享被动，装备任意一式即生效）**  
> 每次施展 **太极绵掌** 任意一式时：当前每有 **1 层【太极】**，该次攻击有 **5%** 几率 **再触发一次同招式伤害**（不消耗 CD、不额外耗真气；满 5 层 = **25%** 再打一次）。

### 4.1 三式拆分

| 招式 | 定位 | 基础效果（基于绵掌） | 等级 10 强化 |
|------|------|----------------------|--------------|
| **一式 · 柔云按掌** | 近身 1～2 格 | 对目标造成 **1 层【绵掌】**（2 回合）；每层受击伤害 **+10%**，消失时扣 **5%** 当前气血，最高 **5 层** | 被动：攻击带【绵掌】目标 **50%** 再叠 1 层（同原版绵掌） |
| **二式 · 云流穿掌** | 直线 3 格 | 对路径敌人各 **1 层【绵掌】**；**武当拳掌伤害 +10%**（4399 拳掌篇：绵掌被动） | 若目标已有【绵掌】，伤害 **+20%** |
| **三式 · 太极绵劲** | 自身周围 4 格 AOE | 对所有敌人 **2 层【绵掌】**；并 **消耗 1 层自身【太极】** 使本次伤害 **+30%** | **太极再击**被动显式写入描述：每层太极 **+5%** 再触发一次本招式（与总被动叠加，实现时合并为一条 Proc 即可） |

**Proc 实现建议**

```
OnHit(太极绵掌任意式):
  procChance = 0.05 * GetBuffStack(太极, caster)
  if Random() < procChance:
    RepeatLastSkillDamageInstance()  // 克隆天魔手/绝弦无音的多段 proc 写法
```

**克隆源**

- 绵掌：Debuff 与被动叠层  
- 武当长拳 / 韦陀掌：三式距离、CD、精通成长模板  
- 天魔手 + 绝弦无音：多段「再击一次」Proc 逻辑

## 5. 拳武器：混元缠丝手

**定位**：拳类武器，**仅宇文逸 / 或仅本传承使用者可装备**（克隆天魔手 Restrictions）。框架照 **天魔手**，效果改为 **太极/武当** 语义。

### 5.1 设计（对标天魔手）

| 天魔手 | 混元缠丝手（建议） |
|--------|---------------------|
| 攻击 **必暴击** | 攻击 **必暴击**（保留，天魔手核心手感） |
| 命中随机附加 **天魔六通** 之一 | 命中随机附加 **太极印** 之一（见下表） |
| 多段招式每段独立触发 | 同左 |

**【太极印】随机 6 种（对应天魔六通结构）**

| 太极印 | 效果（2 回合） |
|--------|----------------|
| 阴阳 | 目标受到伤害 **+10%** |
| 粘劲 | 目标移动力 **-1** |
| 卸力 | 目标攻击 **-8%** |
| 引劲 | 目标闪避 **-15%** |
| 封脉 | 目标真气回复 **-20%** |
| 归元 | 施术者获得 **1 层【太极】** |

**白字属性（参考天魔手品阶）**

- 拳掌精通 **+大**  
- 力道 / 根骨 **+中**  
- 特殊：**武当派招式暴击伤害 +15%**

**克隆源**：Items 表 `天魔手` → 改 RandomDebuffPool 为上述 6 种 Buff ID。

## 6. 饰品：真武太极坠

**定位**：饰品（项链/玉佩槽）。**武当专属**，与【太极】层数、风云太极经联动。

### 6.1 效果

| 类型 | 效果 |
|------|------|
| 属性 | 根骨 **+15**，内功 **+15**，最大真气 **+8%** |
| 被动 1 | 战斗开始 **+1 层【太极】**（与心法叠加，快速启动） |
| 被动 2 | 每有 1 层【太极】，**暴击率 +3%**（5 层 = +15%） |
| 被动 3 | 当【太极】达到 **5 层** 时，消耗全部太极层数，本回合 **武当派招式伤害 +50%**（每场 **1 次**，CD 可设为 0 但 Flag 每场一次） |

**克隆源**：高阶饰品（如传承饰品类）+ 终局「真武太极」相关 Buff 的触发写法（仅借逻辑，数值自拟）。

## 8. 推荐配装与强度边界

**二周目开局推荐栏位**

| 槽位 | 装备 |
|------|------|
| 被动心法 | 风云太极经 |
| 拳掌 | 太极绵掌 一/二/三式 |
| 轻功 | 纵云梯 |
| 武器 | 混元缠丝手 |
| 饰品 | 真武太极坠 |

**强度自检**

- 50,000 点买 **完整体系**，应强于单本玉龙/天山，但不应超过社区「传承 8 合一」  
- **太极 +15%/层 × 5 = +75% 武当伤** 为心法 10 级核心，需限制仅 **武当 Tag**  
- **绵掌再击 25% 上限** 配合 **天魔式必暴**，对 Boss 需依赖 CD/真气，避免无限连

## 9. 实现顺序（给 Modder）

1. 解包 `Items.uasset`、`Skills.uasset`、`Buffs.uasset`、`Inherit.uasset`
