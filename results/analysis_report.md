## 2. 指标定义与计算（与 `docs/consensus.md` 一致）

### 2.1 周收益率

对相邻两个净值报告日 \(t-1\) 与 \(t\)（按表中时间顺序相邻行）：

\[
r^{(\mathrm{产品})}_t = \frac{\mathrm{NAV}_t}{\mathrm{NAV}_{t-1}} - 1
\]

分别对「对冲9号累计净值」「CTA实盘净值」计算，得到两条周收益序列。  
**依据**：材料为周度净值序列，相邻行即为相邻报告周。

### 2.2 Pearson 线性相关系数

对样本量 \(n\) 的一对序列 \(\{x_i\}\)、\(\{y_i\}\)（此处 \(x\) 为对冲9号周收益，\(y\) 为 CTA 周收益）：

\[
r_{xy} = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}
{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2}\sqrt{\sum_{i=1}^{n}(y_i - \bar{y})^2}}
\]

其中 \(\bar{x},\bar{y}\) 为样本均值。

### 2.3 解释口径（本项目采用）

- **弱线性相关**：\(|r_{xy}| < 0.30\)（实务中常用的经验阈值，便于与「中等」「较强」区分；非统计检验显著性）。  
- **判定**：若 \(|r_{xy}| < 0.30\) 且接近 0，则表述为两产品**周收益线性相关性弱**。

## 4. 主要结果

| 指标 | 数值 |
|------|------|
| Pearson \(r\)（对冲9号周收益 vs CTA 周收益） | **0.079718**（计算值，六位小数） |
| 决定系数 \(R^2 = r^2\) | 约 **0.006355**（周收益波动中可被线性解释的比例极低） |
| 对冲9号周收益样本均值 | 约 **0.183%** |
| CTA 周收益样本均值 | 约 **0.097%** |

### 4.1 结论（基于上述材料与定义）

- \(r \approx 0.080\)，**远低于** 0.30，属于 **弱线性相关**。  
- 在重叠样本内，两产品**周度收益同向线性联动很弱**，从分散化角度可理解为：**二者周收益缺乏稳定的线性同涨同跌关系**（仅指本样本、本频率、本计算方法下的线性相关）。

### 4.2 局限（须在对外使用时保留）

- 结论仅针对**表中周度净值、相邻周收益率**；换频率（如日度）或换计算方法（如对数收益、滚动相关）结果可能不同。  
- 未做显著性检验；若需 p 值，应在共识文件中补充检验方法后再执行。  
- 过往业绩不代表未来表现；本分析不构成投资建议。
