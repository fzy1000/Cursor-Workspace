# 武功碎片图鉴（完整词条版）

> **用途**：卡牌融合成长游戏素材库（配合同目录 `wuxia-card-fusion-roguelike-design.md`）  
> **本版重点**：统一战斗词条——暴击、破防、防御力、定神、虚弱、吸收伤害、反伤等均可出现在碎片上。  
> **说明**：名称取自经典武侠意象；数值为游戏原创建议值。  
> **风格**：当前 `style/` 无书面规范，本稿中性列表体。

## 0. 完整词条词典

### 0.1 面板属性（可被碎片用 % 或定值加）

| 面板 | 代号 | 作用 |
|------|------|------|
| 根骨 | BONE | 生命上限、受疗、防御力下限 |
| 力量 | STR | 外功伤害 |
| 身法 | AGI | 暴击率基础、闪避、先手 |
| 内力 | NEI | 内功伤害、吸内上限、部分吸收伤害效率 |
| 真气 | QI | 技能总倍率 |
| 悟性 | INS | 融合稳定（非战斗） |
| 心境 | WIL | 定神抗性、抗心魔 |
| **防御力** | DEF | 按公式减免受到的伤害（与「伤害减免%」分乘区，见 §0.4） |
| **破防** | PEN | 按比例忽视目标防御力 / 伤害减免 |
| **暴击率** | CRIT | 触发暴击的概率 |
| **暴伤** | CDMG | 暴击时伤害倍率（基础建议 150%） |
| **定神** | FOCUS | 抵抗眩晕/心魔/迷雾/封穴等控制与干扰的概率或减效 |
| **吸收伤害** | ABSORB | 开战或触发时获得「伤害池」，优先扣池再扣血（可与护盾并存：先吸收池，再护盾，再生命） |
| **反伤** | THORN | 受到伤害时反弹一定比例给攻击者（可被敌破防部分削弱） |

> 写法：`防御力+20%` / `防御力+15`（定值）；`破防+12%`；`定神+25%`；`吸收伤害+10%最大生命` 或 `吸收伤害+80`（定值池）。

### 0.2 进攻类词条

| 词条 | 含义 | 白→金参考 |
|------|------|-----------|
| 造成伤害+ | 最终伤害加算乘区 | 5%→30% |
| 外功伤害+ / 内功伤害+ | 分系伤害 | 6%→35% |
| **暴击率+** | 提升暴击概率 | 3%→18% |
| **暴伤+** | 暴击倍率增加（如 +30% → 暴击打 180%） | 10%→40% |
| **破防+** | 忽视目标防御力与减伤的比例 | 5%→30% |
| 吸血 | 造成伤害的 X% 回复生命 | 4%→20% |
| 吸内力 | 吸取对手内力并转化为自身内力 | 3%→25% |
| 命中+ | 降低被闪避概率 | 4%→15% |

### 0.3 防御 / 生存类词条

| 词条 | 含义 | 白→金参考 |
|------|------|-----------|
| **防御力+** | 提高 DEF 面板（% 或定值） | 8%→40% 或 +5→+40 |
| 伤害减免+ | 独立乘区减伤（在防御力之后） | 4%→25% |
| **吸收伤害** | 获得可吸收量；耗尽前不受直接生命伤害 | 开战 5%→20% 最大生命；或受击触发 |
| 护盾 | 额外护盾值（通常不可被吸血，可被破防部分穿透） | 6%→15% 最大生命 |
| **反伤** | 反弹受到伤害的 X% | 6%→25% |
| 闪避+ | 完全免伤概率 | 4%→18% |
| 受疗+ | 回复效果增强 | 10%→30% |
| **定神+** | 抵抗控制/心魔/干扰；被控持续时间缩短 | 8%→35% |

**吸收伤害 vs 护盾 vs 伤害减免（别混用）**：

| 机制 | 区别 |
|------|------|
| 伤害减免% | 按比例少挨打，池子不耗尽 |
| 防御力 | 用公式压伤害，持久属性 |
| 护盾 | 额外条，破了就没 |
| **吸收伤害** | 独立伤害池，可设定「只吸外功」「只吸内功」或「全能吸」；可被**破防**按比例直击生命 |

### 0.4 结算顺序（建议）

```
原始伤害
  → 命中/闪避判定
  → 破防：按破防%忽视防御力与部分减伤
  → 防御力公式减伤
  → 伤害减免% 
  → 暴击判定（暴伤）
  → 先扣「吸收伤害」池 → 再扣护盾 → 再扣生命
  → 反伤结算（基于扣生命+护盾的实际量，或基于吸收前，需统一；建议按「破吸前伤害」反弹）
  → 吸血 / 吸内力（按实际造成伤害）
  → 附加负面 Buff
```

防御力简易公式（可调）：

```
防御减伤比 = DEF / (DEF + 100)    // DEF=100 约减半
实际伤害 = 原始 * (1 - 防御减伤比 * (1 - 破防%)) * (1 - 伤害减免%) * 暴击倍率
```

### 0.5 负面 / 控制 Buff（给对手）

| Buff | 效果 | 常见来源 |
|------|------|----------|
| **虚弱** | 造成伤害-15%~30%；可叠 2 层 | 音、化功、泄劲进阶、佛掌震慑 |
| 破绽 | 受到伤害+10%~25% | 剑、破招 |
| 封穴 | 下次攻击伤害-30% 或不能放绝招 | 点穴、佛指 |
| 内伤 | 内力恢复禁止；内功伤害-20% | 化功、震伤 |
| 中毒 | 每回合损血；可叠 | 毒 |
| 寒霜 | 身法-15%；先手-1 | 阴毒、冰 |
| 灼焰 | 每回合损血；伤害减免-8% | 纯阳、九阳 |
| 眩晕 | 跳过行动（受**定神**抵抗） | 棒、音、奇门 |
| 心魔 | 暴击率-10%；定神检定惩罚（受定神抵抗） | 魔功 |
| 泄劲 | 力量/根骨-10% | 化骨、吸星 |
| 迷雾 | 命中-15% | 悲酥、奇门 |
| 破防易伤 | 自身防御力-20%（被上破甲） | 独孤、点穴高阶 |

> **定神**专门克制：眩晕、心魔、迷雾、封穴（部分）。定神 100% 不代表免疫，建议 `抵抗率 = 定神 / (定神 + 80)`。

### 0.6 品质与词条强度

| 品质 | 词条数 | 暴击率 | 破防 | 防御力 | 定神 | 吸收伤害 | 反伤 | 虚弱等 |
|------|--------|--------|------|--------|------|----------|------|--------|
| 白 | 1~2 | +3~5% | +4~6% | +8~12% | +6~10% | 少 | +5~8% | 弱/低概率 |
| 蓝 | 1~2 | +5~8% | +6~10% | +12~16% | +10~14% | 开战 5%~8%生命 | +8~12% | 单种 |
| 紫 | 2 | +8~12% | +10~15% | +16~22% | +14~20% | 8%~12% | +10~15% | 明确 |
| 银 | 2~3 | +10~14% | +15~22% | +22~30% | +20~28% | 12%~16% 或触发 | +15~20% | 强 |
| 金 | 2~3 | +12~18% | +20~30% | +30~40% | +25~35% | 15%~25%+机制 | +18~25% | 强+传奇 |

**软帽（四槽合计建议）**：暴击率 60%；破防 50%；防御力% 80%；伤害减免 50%；反伤 40%；吸收池单场不超过最大生命 40%；定神 80%。

### 0.7 词条战力折算（纯文字检定局）

```
≈ 伤害%*0.25 + 暴击率*0.15 + 暴伤*0.08
  + 破防*0.2 + 防御力%*0.15 + 减伤%*0.15
  + 吸收%(相对生命)*0.12 + 反伤*0.1 + 定神*0.08
  + 吸内力*0.2 + Debuff分(虚弱/破绽等 1~5)
```

## 10. 数量与融合随机（与主设计单 §4.4 对齐）

仍为 **79** 枚。碎片上的词条数字是**奖池基准值**，不是融合保证值。

每次合成：

1. 双方词条进入奖池  
2. 每条独立 roll：**并入 / 数值变异并入 / 顶替已有 / 丢失 / 异化**  
3. 并入时数值再 × 随机浮动（可变强可变弱）  
4. 整次再 roll **结构事件**（双全共鸣、强者吞并、互相顶替、精炼浓缩、驳杂混入、走火反噬等）  
5. 受成品词条条数上限约束，多了必须丢或顶替  

**因此：同一对碎片融十次，可以十种词条组合。** 无固定「A+B=固定C」配方。

详见：同目录 `wuxia-card-fusion-roguelike-design.md` §4.4。
