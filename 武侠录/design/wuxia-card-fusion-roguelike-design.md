# 武侠卡牌融合成长 · 游戏设计单

> **品类**：文字 + 简单插图 · 卡牌融合 Roguelike · 三幕闯关  
> **一句话**：南水赤霄 → 北地玄霜 → 中原东瀛，三劫三 Boss；每次开局随机属性/难度/支线，用 **4 槽武功** 与 **融合成长** 殊途同归。  
> **风格说明**：当前 `style/` 无书面写作规范，本稿采用中性专业结构。  
> **性质**：原创设计稿（非材料分析）；数值为建议初值，实装后需调参。

---

## 0. 设计目标

| 目标 | 做法 |
|------|------|
| 可重玩 | 属性、难度、事件池、融合结果全随机；路线组合 ≥ 30 种「可感知差异」 |
| 殊途同归 | 固定三幕骨架 + 三 Boss 身份；支线只改变「怎么走到 Boss 前」 |
| 成长有代价 | 武功槽仅 4；融合可成可败；强化属性 vs 追求融合二选一常冲突 |
| 低美术成本 | 卡面 = 标题 + 短文 + 1 枚简单插图/剪影；场景用文字渲染 |

## 1. 主线骨架（固定，每次必走）

**世界观标题（暂定）**：《三劫尘剑》

**固定叙事轴**（对标「风云 1 / 2 / 3」三段大事件；地理上南 → 北 → 中原）：

| 幕 | 大事件名 | 叙事功能 | Boss（身份与野心固定，登场方式可变） |
|----|----------|----------|--------------------------------------|
| **第一劫** | 《南水三十六》 | 卷入南方水路争夺，第一次生死 | **Boss A**「赤霄岛岛主」 |
| **第二劫** | 《北地霜刃》 | 北方门派遭屠，卷入存亡之争 | **Boss B**「玄霜宫主」 |
| **第三劫** | 《中原棋局》 | 少林武当重伤，决战外来霸者 | **Boss C**「东瀛霸王」 |

### 1.1 三 Boss 设定（已定）

| Boss | 野心（本幕主冲突） | 玩家卷入方式（殊途，文案可变） |
|------|--------------------|--------------------------------|
| **赤霄岛岛主** | 统一并霸占**南方三十六水路** | 护航、夺旗、卧底、水盗反水、为某帮主出头等 → 最终必须对决岛主 |
| **玄霜宫主** | 灭掉北方**崆峒、雪山派、铸剑山庄、莲花寺**，一统北地 | 勤王、复仇、护送遗孤、偷学禁功、卖友求荣等 → 最终必须对决宫主 |
| **东瀛霸王** | 挑拨中原武林，用计**重伤少林与武当当代掌门**，准备一统中原 | 追查奸细、救护掌门、识破离间、借刀、入局反杀等 → 最终必须对决霸王 |

> **殊途同归规则**：无论本局走侠义 / 魔功 / 隐世 / 情缘哪条，**三 Boss 必须按序击败** 才算通关。改变的是：途中卡牌池、融合倾向、Boss 战前的「检定修正」、以及结局旁白的一两句差异。  
> **野心线不跳过**：每幕随机事件都围绕「阻止 / 利用 / 旁观后被迫出手」该 Boss 的野心，但幕末收敛到同一场 Boss 战。

### 1.2 Boss 档案（文案与事件挂钩）

**赤霄岛岛主（第一劫）**

- **地盘**：南方江海、三十六水路帮旗  
- **野心一句**：水路只留一面旗——赤霄。  
- **本幕压力**：商路断、帮会被血洗、悬赏令满天；玩家无论侠/盗，都会被卷进「谁主南水」。  
- **败后世界变化**：南水暂定，北方霜讯传来（导入第二劫）。

**玄霜宫主（第二劫）**

- **屠名单（固定提及）**：崆峒、雪山派、铸剑山庄、莲花寺  
- **野心一句**：北地只留一座宫——玄霜。  
- **本幕压力**：四派或燃或散，遗孤、遗剑、遗书成事件素材；玩家可勤王、趁火、复仇，但幕末必撞宫主。  
- **败后世界变化**：北地喘息，中原急报——少林、武当掌门先后重伤（导入第三劫）。

**东瀛霸王（第三劫）**

- **手段**：挑拨中原门派互疑，用计重伤**少林当代掌门**与**武当当代掌门**，趁群龙无首一统中原。  
- **野心一句**：中原武林，入我彀中。  
- **本幕压力**：真假英雄帖、伪诏离间、细作、两派余弟子求援；武力检定外可插一次「心」检定破计。  
- **败后**：通关。旁白按标签分写「中原暂定 / 你取而代之之忌 / 功成身退」等差异句，不改 Boss 身份。

每幕结构（一次 Run 内重复 3 次）：

```
幕开始叙事（短）
  → 本幕 N 个随机节点（默认 5）
  → 节点产出：属性卡 / 武功碎片 / 事件抉择 / 小怪检定
  → 幕末「备战」：可融合 / 可弃牌整理槽位
  → Boss 检定（胜→进入下幕；败→本局结束或残血续命规则见 §6）
```

## 2. 核心循环（单局）

```
开局掷「命格」→ 随机基础属性 + 随机难度种子 + 随机开局碎片
  → 进入第 N 劫节点循环（抽卡/选卡/融合）
  → 幕末 Boss 战力检定
  → 三劫全胜 → 通关结语（按路线标签拼旁白）
```

**玩家每回合在节点上通常只做一件事**：

1. **收卡**：拿属性强化，或拿武功碎片  
2. **融合**：两张碎片 / 碎片+武功 / 两门武功 → 新结果（占槽）  
3. **抉择**：剧情选项（改标签、改下一路由权重、改检定）

## 3. 卡牌类型

### 3.1 属性卡（永久，本局有效）

六维（建议保持少，便于文字表达与检定）：

| 属性 | 代号 | 检定主要用途 |
|------|------|--------------|
| 力 | STR | 刚猛、破防、硬碰 |
| 敏 | AGI | 先手、闪避、连招 |
| 内 | INT | 内功、护体、持续 |
| 心 | WIL | 抗心魔、奇遇、融合稳定 |
| 悟 | INS | 融合成功率、碎片领悟 |
| 气 | QI | 总战力系数、爆发 |

**随机属性（开局）**：

- 六维各 roll：`3d4` 取中间值思路简化为 **2~7 随机，总和固定 30**（点满分配，保证可通关下限）  
- 额外「命格词条」1 条（见 §7），可加减某一维或改融合倾向

**节点获得属性**：`+1~+3` 单维，或「双修 +1/+1」，或「险修：+3 但另一维 -1」。

### 3.2 武功碎片卡

- **五色品质**：白 < 蓝 < 紫 < 银 < 金（越高词条%与机制越强）  
- **门类**：佛 / 道 / 魔 / 外道 / 名门外功 / 身法 / 内功  
- **词条类型**（完整词典见碎片图鉴 §0）：  
  - 进攻：造成伤害%、暴击率、暴伤、破防、吸血、吸内力  
  - 防御：防御力、伤害减免%、吸收伤害、护盾、反伤、闪避、定神  
  - 负面：虚弱、破绽、封穴、内伤、中毒、寒霜、灼焰、眩晕、心魔、泄劲、迷雾、破甲  
- 单独不成武功；须融合后词条进 4 槽武功  
- **完整图鉴（79 枚）**：[`wuxia-martial-fragments-catalog.md`](wuxia-martial-fragments-catalog.md)

示例：

- `金刚不坏·体`：防御力+22%，吸收伤害10%生命，反伤+10%  
- `独孤剑·破气式`：破防+18%，破绽，敌防御力-10%  
- `碧海潮生·曲`：虚弱20%，眩晕20%，对计谋型+20%  
- `拈花指·妙谛`：定神+18%，心境+12%

### 3.3 武功卡（占槽，最多 4）

字段建议：

| 字段 | 说明 |
|------|------|
| 名称 | 显示名 |
| 标签 | 最多 3 个（剑、掌、内、魔、佛、毒、阵…） |
| 战力贡献 | 对 Boss 检定的基础分 |
| 特效 | 一条短规则（先攻、破气、反伤、稳融合…） |
| 风险 | 可选：心魔、反噬、克己 |

### 3.4 事件卡 / 抉择卡

短文 + 2~3 选项；选项写入 **路线标签** 与即时奖惩。

### 3.5 难度修正卡（对玩家半透明）

不进手牌，进「本局种子」：影响节点敌强、融合暴毙率、Boss 阈值。

## 4. 融合系统（成长核心）

### 4.1 槽位规则

- **武功槽 = 4**（含主动与被动，不区分也可，降低复杂度）  
- 碎片不占槽，但 **背包上限建议 6**；超限须丢弃或强制融合  
- 融合产物若超 4 槽：必须替换一门旧武功（被替者可分解为 1 枚低阶碎片，带回馈）

### 4.2 合法融合配方（建议）

| 输入 | 输出倾向 |
|------|----------|
| 碎片 + 碎片 | 新武功（凡~良） |
| 碎片 + 武功 | 同系强化 / 异系变异 |
| 武功 + 武功 | 高阶融合（奇~绝）或互斥暴毙 |
| 属性卡「祭炼」+ 武功 | 不占配方次数：付属性换稳定度或战力 |

### 4.3 融合总判定（有好有坏）

```
稳定度 = 基础50%
        + 悟*3%
        + 心*2%
        + 同标签加成(+15%)
        + 难度种子惩罚(-0%~-25%)
        + 连续融合疲劳(-5%/次，本幕重置)
```

**结果档（先抽档，再进词条随机 §4.4）**：

| 档位 | 权重思路 | 对词条随机的影响 |
|------|----------|------------------|
| 大成 | 稳定度高时↑ | 偏「双全继承 / 数值上浮」；词条槽上限 +1（临时） |
| 小成 | 常见 | 标准随机表 |
| 驳杂 | 中 | 偏「丢失 / 顶替 / 数值下浮」；可能混入无关词条 |
| 走火 | 低~中 | 继承后强制加 1 条反噬词条；定神/防御易被砍 |
| 散功 | 低 | 材料毁，或只退 1 碎片；无成品 |
| 心魔武学 | 极低（魔线↑） | 高数值 + 强制负面；词条更易「全加但带毒」 |

**设计意图**：每次合成都是开盲盒——同样两张素材，词条组合与数字都可能不同。

### 4.4 词条随机合成（核心）

> **原则**：素材词条只是「奖池」，不是保证继承。每次融合对奖池做一次随机结算。

#### 4.4.1 输入与词条池

| 融合类型 | 词条池怎么来 |
|----------|--------------|
| 碎片 A + 碎片 B | 池 = A 全部词条 ∪ B 全部词条 |
| 碎片 + 已有武功 | 池 = 碎片词条 ∪ 武功当前词条 |
| 武功 + 武功 | 池 = 两门武功当前词条 |

每条词条带：`类型ID`（如破防）、`数值`、`来源`（A/B）、可选 `传奇标记`。

**成品词条上限**（建议）：

| 武功品质倾向 | 词条条数上限 |
|--------------|--------------|
| 白蓝融出 | 2~3 |
| 紫 | 3~4 |
| 银 | 4 |
| 金素材参与 | 4~5（大成可达 5） |

超过上限的必须在随机过程中 **丢掉或顶替**，不能无脑全加。

#### 4.4.2 单条词条的四种命运（对池中每一条独立 roll）

对池里每条词条 roll 一个命运（权重随档位变）：

| 命运 | 含义 | 大成 | 小成 | 驳杂 | 走火 |
|------|------|------|------|------|------|
| **保留并入** | 进入成品 | 45% | 35% | 20% | 25% |
| **数值变异后并入** | 并入但数字变 | 30% | 30% | 25% | 25% |
| **顶替** | 挤掉成品里已有的一条（随机或同类型） | 10% | 15% | 25% | 20% |
| **丢失** | 本条不出现在成品 | 10% | 15% | 25% | 20% |
| **异化** | 变成同门类另一词条（如暴击→暴伤，减伤→吸收伤害） | 5% | 5% | 5% | 10% |

若「保留/变异」后超过条数上限 → 自动改为对已有词条 **顶替** 或 **丢失**（各 50%）。

**同类型冲突**（例：两边都有「破防」）：

| 结果 | 权重 | 效果 |
|------|------|------|
| 合并加算 | 40% | 破防取 A%+B% 再 × 数值浮动，封顶见软帽 |
| 取高 | 30% | 只留较大值，再浮动 |
| 取低 | 15% | 只留较小值（驳杂权重↑） |
| 顶替为单条随机值 | 15% | 在 min~max 间重 roll |

#### 4.4.3 数值浮动（每次并入都可能变）

```
最终值 = 基础值 × (1 + U)
U ~ 均匀分布，区间随档位：

大成：U ∈ [-0.10, +0.25]   // 更容易变强
小成：U ∈ [-0.15, +0.15]
驳杂：U ∈ [-0.30, +0.10]   // 更容易变弱
走火：U ∈ [-0.25, +0.35]   // 大起大落
```

- 百分比类保留整数（如破防 18% → 14%~23%）  
- 概率类 Debuff（虚弱 20%）同样浮动  
- **传奇词条**（金专属规则）：数值浮动减半，但仍可能 **丢失**（丢失权重降为表内的 50%）

可选：**悟性** 每 5 点使浮动下限 +2%（更不易大崩）；**心境** 降低走火档权重。

#### 4.4.4 整次融合的「结构事件」（额外再 roll 1 次）

在逐条命运之后，再抽 **1 个结构事件**（决定体感差异）：

| 事件 | 权重 | 效果 |
|------|------|------|
| 双全共鸣 | 12% | 尽力保留双方核心词条；若超上限，上限临时 +1 |
| 强者吞并 | 18% | 以品质/战力较高的一方为主；另一方每条额外 +20% 丢失率 |
| 互相顶替 | 15% | 成品先清空，从池中随机抽满上限；强调「顶掉旧的」 |
| 精炼浓缩 | 15% | 条数偏少（上限-1），但并入数值额外 ×1.15 |
| 驳杂混入 | 12% | 随机插入 1 条与双方无关的白/蓝词条（或一条弱负面） |
| 走火反噬 | 10% | 强制 +1 负面：防御力-10% / 定神-15% / 每回合自伤 2% 等 |
| 平平无奇 | 18% | 无额外修正，只吃逐条命运 |

（权重可再乘档位：大成时「双全共鸣」「精炼」↑；驳杂时「互相顶替」「驳杂混入」↑。）

#### 4.4.5 流程伪代码

```
pool = 收集(素材A词条, 素材B词条)
档位 = 抽档(稳定度)
上限 = 按品质算词条上限(档位)
result = []

for affix in pool:
    fate = 抽命运(档位)
    if fate == 丢失: continue
    if fate == 异化: affix = 同门随机另一词条(affix)
    value = 数值浮动(affix.value, 档位)
    if 与 result 同类型:
        result = 解决同类型冲突(result, affix, value)
    else if fate == 顶替 and result 非空:
        随机移除 result 一条（优先同类型，否则任意）
        result.add(affix, value)
    else:
        result.add(affix, value)
    while len(result) > 上限:
        随机丢弃 result 一条 或 被新条顶替

结构事件 = 抽结构事件(档位)
应用结构事件(result, pool, 结构事件)

if 档位 == 走火 or 结构事件 == 走火反噬:
    result.add(随机反噬词条())

生成武功名与标签(素材, result)
return 武功
```

#### 4.4.6 同料不同果（给玩家看的例子）

素材：`降龙·亢龙有悔`(力量+20%，外功+18%，破防+14%)  
　　＋`吸星大法·漩`(吸内力20%，吸血10%，造成伤害+18%，虚弱15%)

| 第 N 次 | 可能成品词条 |
|---------|----------------|
| 第一次 | 力量+23%，破防+12%，吸内力+17%，造成伤害+16%（丢了吸血与虚弱；力量上浮） |
| 第二次 | 外功+18%，吸内力+22%，吸血+9%，虚弱+18%，防御力-10%（双全偏多但走火反噬） |
| 第三次 | 破防+19%，造成伤害+21%（精炼浓缩：条少数大；顶掉力量与吸内） |
| 第四次 | 力量+15%，外功+14%，中毒1层起手，造成伤害+10%（驳杂混入毒；原词条下浮） |

→ **没有固定配方表**；只有奖池 + 随机规则。可分享 Seed 复现。

#### 4.4.7 玩家可读提示（UI）

融合前只显示：

- 「词条来源预览」（双方词条列表）  
- 「本次稳定度 / 档位倾向」（模糊：平稳 / 躁动 / 凶险）  
- 不预告具体数字  

融合后播报一句：

> 亢龙吞星——破防得以保全，吸星之力大半留下，然「吸血」在冲撞中散去；破防 14%→17%。

### 4.5 标签相性（简表）

| | 剑 | 掌 | 内 | 魔 | 佛 |
|--|----|----|----|----|-----|
| 剑 | 稳 | 奇 | 稳 | 危 | 奇 |
| 掌 | 奇 | 稳 | 稳 | 危 | 稳 |
| 内 | 稳 | 稳 | 稳 | 危 | 稳 |
| 魔 | 危 | 危 | 危 | 稳(魔) | 极危 |
| 佛 | 奇 | 稳 | 稳 | 极危 | 稳 |

- **稳**：成功率↑  
- **奇**：易出非常规特效  
- **危**：走火/心魔权重↑，成功则战力更高

## 5. 战力与 Boss 检定

不做成复杂连招 UI；**文字结算 + 简单插图演出**。

### 5.1 战力分

```
战力 = (力*1.0 + 敏*0.8 + 内*1.0 + 气*1.2)
      + Σ 武功战力贡献
      + 克制修正（武功标签 vs Boss 弱点）
      + 路线修正（本局标签）
      - 负面特效惩罚
```

### 5.2 胜负

```
需求值 = Boss基础阈值 × 难度系数 × 幕数成长
检定差 = 战力 - 需求值 + random(-3, +3)   // 小随机，避免纯计算器

差 ≥ +8  ：完胜（额外奖励碎片）
差 0~+7 ：险胜（可能受伤：随机 -1 属性）
差 -5~-1：可选「绝境抉择」（付代价再 roll 一次，或逃亡失败结束）
差 ≤ -6 ：败北，本局结束
```

### 5.3 Boss 弱点（固定，方便构筑）

| Boss | 战斗意象 | 弱点标签 | 抗性 |
|------|----------|----------|------|
| **赤霄岛岛主** | 水寨连环船、刚刀霸江 | 内、掌、身法（破船阵/近身卸力） | 抗「纯力硬刚、无水战技巧的蛮打」 |
| **玄霜宫主** | 霜气封穴、门派围杀余党 | 剑、火/刚猛、破阵 | 抗「单一龟壳内功、一味防守」 |
| **东瀛霸王** | 借刀杀人、奇计与快剑 | 佛、心（WIL）、中原正统融合武学 | 抗「凡品堆砌、无特效的杂学」；计谋战可追加一次心检定 |

文字表达示例：

> 船头浪起，赤霄岛主刀劈桅杆。你以「混元绵掌」卸开三刀，内息一卷，岛主退半步……  
> 【检定】战力 42 vs 需求 38 → 险胜。力 -1（刀气入臂）。

## 6. 难度随机

开局 roll **难度种子**（玩家可见名，细则可半隐藏）：

| 种子名 | 效果 |
|--------|------|
| 平潮 | 标准阈值、标准融合 |
| 刀口 | Boss +15%，完胜奖励 + |
| 心魔潮 | 融合危档权重↑，魔线事件↑ |
| 机缘薄 | 碎片少、属性多（或相反） |
| 天妒 | 小随机检定区间变大 |
| 贵人运 | 每幕必出一次「高人指点」稳融合 |

**幕内小怪/险地**：用同一套检定，阈值约为当幕 Boss 的 40%~60%，失败多为扣属性或丢碎片，不直接死（第三劫可加强）。

## 7. 随机剧情：如何「几十种路线」却殊途同归

### 7.1 方法：模块化，不写 40 条完整小说

用 **3 层组合** 生成「可感知不同」的路线：

1. **开局命格**（8）  
2. **每幕路径原型**（6）——三幕各抽，但受标签权重影响  
3. **幕内事件包**（每幕 8 个事件池，抽 5 个）

理论组合远超几十；对外宣称与策划验收用 **「32 条命名路线」** 作为设计目标（见 §7.4），其余为变体。

### 7.2 路线标签（隐藏评分，决定旁白与权重）

每局累计五维标签分（事件选项加减）：

| 标签 | 含义 |
|------|------|
| 侠 | 救人、守诺 |
| 魔 | 夺、杀、邪功 |
| 隐 | 避世、不争 |
| 情 | 羁绊、守护某人 |
| 执 | 报仇、夺宝、成道 |

通关时取 **最高两标签** 拼结局句（仍是打完三 Boss 后的差异旁白，不是分岐大结局大改）。

### 7.3 每幕「路径原型」6 选一（殊途）

| ID | 原型 | 叙事口吻 | 卡池偏向 | Boss 前修正 |
|----|------|----------|----------|-------------|
| P1 | 名门正统 | 拜入某派外围 | 内、剑、稳融合 | 抗心魔 + |
| P2 | 散修漂泊 | 野路子奇遇 | 碎片多、相性乱 | 悟检定 + |
| P3 | 魔功捷径 | 禁书/血祭 | 魔标签、高危融合 | 战力 +，心 - |
| P4 | 情缘羁绊 | 护送/抉择救人 | 事件多、属性均衡 | 险胜免伤一次 |
| P5 | 复仇执念 | 追凶线 | 力/剑、刚猛武功 | 对 Boss 破防 + |
| P6 | 隐世旁观 | 少管闲事 | 内、心、少战斗节点 | Boss 阈值略↑（战力未砺） |

**同归**：无论 P1~P6，幕末事件链 **收敛到同一 Boss 场景**（文案开头不同，Boss 战同一套检定）。

示例收敛句（第一劫 → 赤霄岛岛主）：

- P1：「水路盟主令下，你代表某帮与赤霄岛主决战夺旗。」  
- P3：「你刚炼成魔功，岛主循魔息杀来，要借你头祭旗统水。」  
- P4：「为护商船与故人，你拦在岛主刀下。」  
→ 都是 Boss A。

第二劫收敛示例 → 玄霜宫主：

- 「崆峒火起，你挡在宫主霜刃前。」 / 「雪山遗孤托孤，你不得不战。」 / 「你本想分一杯羹，玄霜宫主不容旁人。」  

第三劫收敛示例 → 东瀛霸王：

- 「少林掌门吐血未愈，你接下这一战。」 / 「武当来信：奸计已成，唯余你可破局。」 / 「你识破挑拨，反将计就计，与霸王摊牌。」

### 7.4 命名路线 32 条（验收用清单）

用「命格 × 主标签」命名；实装时每条 = 开局命格固定倾向 + 三幕原型权重表。

**命格 8：**

1. 天剑残魂  
2. 药人遗孤  
3. 败门余孽  
4. 富商质子  
5. 哑巴刀客  
6. 尼姑庵外侍  
7. 盗墓书生  
8. 戏班武行  

**主标签路线 4**（侠 / 魔 / 隐 / 执）× 命格 8 = **32**。  
（情可作副标签，不单独占 32，以免膨胀。）

每条路线只需准备：

- 开场 120 字  
- 三幕「入幕句」各 50 字  
- 通关结语 80 字  
- 事件权重表（哪些事件 ID 更容易抽到）

**同归点**：三 Boss 战文案各准备 3 个「入场变体」（按当前最高标签选），战中结算同一套。

### 7.5 幕内事件池（每幕 8，设计最小集）

**第一劫池（南水）**：水路夺旗 / 夜袭商船 / 水匪招安 / 岛主悬赏令 / 三十六帮密会 / 沉船残谱 / 潮汛赌命 / 内应投诚  

**第二劫池（北地）**：崆峒火夜 / 雪山托孤 / 铸剑山庄夺剑 / 莲花寺血阶 / 霜宫来使 / 四派遗书 / 北逃商路 / 祭霜台  

**第三劫池（中原）**：少林掌门重伤 / 武当来信 / 离间伪诏 / 东瀛细作 / 四槽已满须舍 / 两派余弟子求援 / 英雄宴鸿门 / 中原擂台  

每次每幕抽 5 个，顺序随机 → 同局玩家「剧情不同」但长度可控。

## 8. 单局流程（玩家视角）

1. **选或 roll 命格** → 看六维与开局 2 碎片  
2. **看难度种子**  
3. **第一劫《南水三十六》**：5 节点 → 备战融合 → **赤霄岛岛主**  
4. **第二劫《北地霜刃》**：5 节点（池更狠）→ 备战 → **玄霜宫主**  
5. **第三劫《中原棋局》**：5 节点（含强制「舍武」事件）→ 备战 → **东瀛霸王**  
6. **通关**：按标签输出结语 + 本局评价（战力、融合次数、走火次数）

建议一局目标时长：**25~40 分钟**（纯文字）。

| 事件 | 每幕 8，共 24 |
| 路径原型 | 6 |
| Boss | 3 |
| 命名路线文案 | 先做 8 条（一命格×四标签），再扩到 32 |

**融合表生成法（省事）**：  
碎片带 `系列ID + 键位`；同系列合成固定武功；异系列查相性表再 roll 结果档。先做 6 个系列即可撑起 36 武功体验。

**系列**：剑意 / 绵掌 / 养气 / 魔焰 / 罗汉 / 身法

|------|----------|

## 12. 平衡与反腻要点

1. **4 槽**：第三劫强制「四选三舍一」事件，制造终局构筑故事  
2. **属性 vs 融合**：资源节点常互斥（本节点二选一）  
3. **坏融合也是内容**：走火武功可在特定事件「镇压心魔」净化，给翻盘戏  
4. **Boss 必打**：不允许跳过；逃亡仅第一、二劫残局可「以代价跳过小节点」，不可跳 Boss  
5. **随机有种子**：可分享 Seed，便于调参与社区挑战

## 13. 技术实现建议（轻量）

- 引擎：任意（Unity / Godot / 甚至 Ink+网页）均可；逻辑是 **卡表 + 事件图 + 检定**  
- 数据：JSON/CSV 三张主表——`cards` / `events` / `fusions`  
- 剧情：Ink / Yarn / 自研节点脚本；插图用静态 PNG  
- 存档：当前幕、标签分、种子、4 槽、碎片包
