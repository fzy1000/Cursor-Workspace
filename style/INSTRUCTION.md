## 1. 总体原则（必须遵守）

1. **内容与事实**：数据、结论、业绩表述仅来自 `materials/` 与项目共识文件，遵守 `instruments/work-materials-instrument.md`。风格样本与 PDF **不作为**事实来源。  
2. **视觉与版式**：下图两套系二选一（或用户指定混合规则），**版式、配色、页眉页脚、图表习惯**须与所选套系的样本一致。  
3. **套系选用**：优先按用户指令；若任务对应材料中主体明确（如仅黑翼/仅量派），与主体一致；**均不明确时须向用户确认**使用套系 A 或 B。  
4. **语言**：简体中文为主，金融/量化术语保持样本中的正式、客观口径；关键结论可用套系惯用强调色标注（见下）。  
5. **分析类产出路径**：由数据或图表生成的**新文件**（报告、SVG/PNG、导出表等）**默认放入 `results/`**，不在 `style/` 或 `materials/` 根目录随意堆放；引用图表时在说明中写清 `results/` 内文件名。视觉版式仍遵循本文件套系 A/B。

## 2. 套系 A — 量派蓝红（来自两张 PNG 样本）

### 2.1 色彩

- **背景**：白底。  
- **主色（深蓝）**：主标题、表格首行/首列、**底栏通栏**、Logo 图形主色。  
- **辅色（浅蓝灰）**：表格数据区底纹。  
- **强调红**：折线图主线、柱状图中**正值**柱；文内关键百分比（如胜率）可用红色突出。  
- **蓝柱**：样本中**负向**柱状数据使用蓝色柱，与红柱形成对照。  
- **灰**：坐标轴、网格线、**页脚免责声明**小字。

### 2.2 版式结构（单页）

- **页眉区**：左上 **大号加粗深蓝标题**（一句话结论型标题）；右上 **圆形 Logo**（含 π 图形与「QUANT π」字样）。  
- **正文区**：可先为 **➢ 引导的单条要点**；中部 **图表**（带居中副标题，副标题内可对齐文内强调色）。  
- **图表**：X 轴日期标签可 **45° 倾斜**；Y 轴为百分比时需保留清晰网格。  
- **表格**：**深蓝底白字**表头；数据区浅蓝灰底、细白分割线。  
- **页脚**：图表下 **浅灰小号免责声明**；最下方 **通栏深蓝底** — 左为年份块（如「2026年」）、中为**公司全称**（白字）、右为 **灰底页码框**。

### 2.3 气质与内容习惯

- 强调 **超额、胜率、回撤、对标指数** 等量化对比；标题即 **结论导向**。  
- 语气：**分析型、可核验**，避免口号式空泛承诺。

## 3. 套系 B — 黑翼金灰（来自 JPG 样本 + PDF）

### 3.1 色彩

- **背景**：白底为主，模块间 **大留白**。  
- **主文字**：黑/深灰。  
- **强调金（哑光金/芥末金感）**：副标题、小标题装饰、**表头行**、**主数据折线**或主系列柱状图；文中关键词可加金色。  
- **灰**：次数据系列、网格、表框细分、次要图例。  
- **红**：样本中用于 **负值、关键业绩数字强调**（与量派用法不同：黑翼套系中红更偏「数字强调/负向」，具体页以样本为准）。

### 3.2 版式与组件

- **品牌**：右上固定 **「BLACK WING 黑翼资产」** Logo（生成物若无关黑翼产品，仅**借用版式**时应替换为占位说明，避免侵权误用真实 Logo）。  
- **标题**：**主标题黑体加粗**；冒号后可接 **金色短语** 作副标或结论提要（与样本一致）。  
- **文字页**：多使用 **项目符号**；三栏并列对比策略/模块；**圆角胶囊标签**作小节标题；**圆形线描图标**区分策略类型。  
- **图表**：折线图为 **极简网格 + 金色主序列**；柱状图 **金 vs 灰/黑** 区分系列；**数据标签**贴齐柱顶/底。  
- **表格**：**金色表头**（白字或黑字以样本为准）；数据行 **斑马纹**（白与极浅灰）；月度收益矩阵：**年×月网格 + 全年度列**，负值标红。  
- **页脚**：**浅灰小字**数据来源与免责提示（与 PDF 合规页风格一致）。

### 3.3 PDF 所体现的文案与结构习惯（在无关具体业绩数字前提下）

- 首页：**中英文机构名 + 材料类型 + 一句中文定位语 + 官网**。  
- **合规与免责**：独立成页，分条列出「不预示未来、合格投资者、不得公开宣传、复制限制」等；后可接 **合格投资者定义**、协会公示说明等（篇幅与层级与 PDF 类似）。  
- **目录**：大号章节号（如 `01`）+ 章标题；条目含公司概况、多策略价值、产品要素等逻辑（新项目可替换目录文字，**保留编号与层级风格**）。  
- 整体：**私募产品推介**常用的审慎、合规前置、再展开业务的顺序。

## 4. 配图 / 信息图（非整页 PPT）

- **选用套系 A**：主色深蓝 + 白底 + 红色作唯一高亮数据色时，适合「对标指数、超额走势」类图。  
- **选用套系 B**：金 + 灰 + 黑，适合「多策略、相关性、危机区间对比」类图；保持 **细柱、清晰图例、少装饰**。  
- 输出说明中写清：**画幅比例、主色色值意向（或引用上文章节名）、字体为无衬线中文**，并注明数据引用须来自 `materials/`。
