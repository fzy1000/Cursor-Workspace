## 建议继续补充的内容

| 类型 | 说明 | 示例路径 |
|------|------|----------|
| **书面规范** | 称谓、语气、禁用词、段落长度、标题层级 | `style/writing-guide.md` |
| **版式与结构** | 封面要素、目录、章节顺序、页眉页脚说明 | `style/layout-guide.md` |
| **品牌与视觉** | 主色色值、字体名、Logo 使用规则 | `style/brand.md` |
| **范例文件** | 可编辑 `.pptx` 或定稿脱敏样例 | `style/samples/` |
| **术语表** | 固定译名、缩写、单位写法 | `style/glossary.md` |

将文件放入 `style/` 或其子目录即可。若某次任务只需遵循其中一部分，可在对话中说明（例如「仅参考 `writing-guide.md`」）。
